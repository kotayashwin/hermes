# Hermes - XLR8 @IIT Bombay
Source code for our team's (Hermes) car for the freshmen's XLR8 competition conducted at IIT Bombay.
A huge thanks to my teammates and the organising committee for conducting the competition.

This code supports manual control, automatic driving, and ultrasound-based navigation.
This firmware is to be loaded onto a Raspberry Pi Pico W only.
